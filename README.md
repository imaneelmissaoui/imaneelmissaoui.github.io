## Selected case files

- **CASE / 02 — Physiological signal stream** — Processed 500 Hz PPG, ECG and temperature signals into readable monitoring indicators. *Private work; details on request.*
- [CASE / 03 — MRI cohort analytics](https://github.com/imaneelmissaoui/Internship-neurodatascience) — Prepared 2,000+ structural MRI scans for reproducible Parkinson’s research.
- [CASE / 04 — Oncology clinical-trials pipeline](https://github.com/imaneelmissaoui/clinical-trials-oncology-pipeline) *(in progress)* — Building a Python and PostgreSQL pipeline for public ClinicalTrials.gov records.
- [CASE / 05 — Care Compass France](https://imaneelmissaoui.github.io/projects/care-compass/) — Interactive healthcare access dashboard; [source and documentation](https://github.com/imaneelmissaoui/imaneelmissaoui.github.io/tree/main/projects/care-compass/).
