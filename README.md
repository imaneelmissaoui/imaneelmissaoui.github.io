# Imane El Missaoui — Portfolio

Static GitHub Pages version of the “From raw data to human insight” portfolio.

## Publish on GitHub Pages

1. Open the repository `imaneelmissaoui/imaneelmissaoui.github.io`.
2. Remove the old website files from the repository.
3. Upload **the contents of this folder** to the repository root (not the outer folder itself).
4. Commit the changes to the default branch.
5. In **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

The website will be available at:

`https://imaneelmissaoui.github.io/`

## Main files

- `index.html` — website content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and scroll reveals
- `assets/` — logo, favicon, CV and local fonts

No installation or build command is required.
