02 / METHOD

Traceable data.
Clear limits.

The pipeline preserves each source payload in Bronze, standardizes current study attributes in Silver, and builds tested fact, dimension and bridge tables in Gold.

01
Keep source records intact

Store the complete JSON response as JSONB with a run ID and source update date.

02
Model the record grain

Use one latest study row per NCT ID; explode multi-valued conditions, interventions and countries into bridge tables.

03
Validate before reporting

Run dbt uniqueness, not-null, relationship and metric checks before exporting Gold data.

04
Read imaging mentions carefully

Imaging indicators are keyword signals found in public text; they do not classify a trial's clinical purpose.
